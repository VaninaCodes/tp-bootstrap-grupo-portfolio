## Descripción
Sitio web sobre un grupo de desarrolaldores que trabajan en conjuntos para solucionar problemas o crear Soluciones.
En donde el usuario puede acceder a los portafolios personal de cada desarrollador del grupo

## Componentes de Bootstrap utilizados
- Navbar responsivo
- Sistema de grillas (Grid)

- Cards para mostrar imagenes y descripciones
- Carruseles de imagenes
- Iconos
- displays(tamaño en los titulares)
- estilos: text-color , gutter, gap-0, p(padiing)
- flex (d-flex)
